# Car Mods

Ein Unterordner pro Mod mit eigenem README (Ziel, Installation, Status).

- `porsche_956`: Porsche 956 mit Venturi-Unterboden, Bellof Ring 1983. Fertig.
- `f2004_drs_kers`: Kunos-F2004 mit DRS und KERS nach Reglement 2013 und den Reifenmischungen der Formula Hybrid 2018. Gebaut, Test im Spiel offen.
- `f1-mod-fixes`: Korrekturen an den F1-Mods von Cimmerian Iter (2007 bis 2013) und The Race Project (2009), Skripte zum Wiederherstellen und abgestimmte Grids. Angewendet und getestet.
